How to play

Take the first step.

A little preparation, then a whole world to explore.

The game runs on a private computer, so you join through Tailscale first. It is free, and everything you need is right here.

  1. Install Tailscale

    Install Tailscale on the device you will play on, then sign in with your own account, such as Google.

    Download for Windows PCDownload for MacOther devices

  2. Accept the game invite

    Accept the game invite. This adds the game computer to your Tailscale.

    Accept the game invite

    If the invite does not work, ask the person who invited you for a new one.

  3. Open the game

    Make sure Tailscale says Connected, then open the game. Keep Tailscale on while you play.

    Open PokeWorld

  4. Choose your account

    New players: enter a new trainer name to create your account. Returning players: enter your existing trainer name to load your saved progress. Use the same name each time. Only enter your own name, because anyone with access could type any trainer name.

  5. Keep your progress

    Slot 1 syncs to the game server. Other save slots stay in that browser. Use the menu's Save page before you leave.

This website is separate from the game. Opening this page does not grant game access.
